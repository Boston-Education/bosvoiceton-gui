# BosVoiceTon
 An invoice program designed to provide quality-of-life features to make easily and consistently. This program aims to auto-generate invoice Excel sheets based on Google Calendar data.

Please note that this program functionality is mainly provided to the people of Boston Education and I will have this software implemented on another version for general/public use.

## Getting Started
### Prerequisite
You must have the following setup on your machine/account:
- Google
- MySQL
### Installation
1. Go to the "Releases" section located on the right side just below the "About" section (see image below).

> Versions may differ at the time of writing! Just pick the latest display!

2. Download the program
<img width="1214" height="488" alt="Screenshot 2025-09-19 182846" src="https://github.com/user-attachments/assets/d15714c6-4cf2-4004-8ee3-7932a362e399" />

<img width="600" height="142" alt="Screenshot 2025-09-20 004615" src="https://github.com/user-attachments/assets/f526ee14-1f5d-48a1-a579-24f26dbd69a6" />

4. Open **aws_rds_database_info.cfg** and type in the login info. If you have MySQL setup on your machine, your host by default is named *localhost*.
